# La Galerie du Vieux Carré — Preview Master Edition

This build treats the approved preview image as the literal visual specification.

Key implementation decisions:
- The opening hero uses a cropped copy of the approved preview itself so the oil-painting composition, typography, logo placement, scale, color, and spacing match what was approved.
- Invisible accessible link hotspots preserve navigation over the approved visual on desktop.
- The residence spread, oxblood quotation band, compact 4×2 gallery index, parchment treatment, gold ornament, and closing composition are rebuilt to match that same visual system.
- The site then extends naturally into full editorial galleries for Living Room, Bedrooms, Courtyard, Balcony, and the First-Floor Efficiency Apartment.
- All extended gallery photography comes from the user's supplied property photographs and is shown sharp, unblurred, and unfiltered.
- The street address is not printed by the website.
- Matterport remains embedded as the digital twin.

The booking form is a visual preview until a live booking destination is supplied.
