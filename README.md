# La Galerie du Vieux Carré — full-bleed hotel film build

Deploy the contents of this folder at the project root.

This build intentionally uses one video element per cinematic hero. The opening approved painting dissolves into the first full-screen film; the live typography appears only after the painting has faded so there is no duplicate text. The second film is a single edge-to-edge background layer with the hotel copy and booking actions over it. There is no blurred portrait duplicate or video card treatment.
